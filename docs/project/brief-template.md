# Client brief template

Copy to `docs/project/brief.md` after collecting actual answers. This template is not an approved client brief.

- Excluded deliverables:

## Selected apps

For each selected app, record purpose, users, required pages/features/workflows, priorities, mock versus production behavior, and acceptance criteria. After confirmation, add the planned workspace, port, auth boundary, and data ownership.

## Brand and assets

Record direction, voice, logos, copy, images, references, supplied assets, and missing assets.

## Integrations and constraints

Record services, existing systems, access owner, environment variable names, deployment needs, deadlines, and constraints. Never save secret values.

## Open questions and decisions

Record unresolved questions, assumptions to confirm, decisions, and deliberately retained example references.

## Confirmation record

Set `Status: confirmed` and replace `Confirmation evidence: TBD` with the user's actual approval (message/date or a short quote) only after explicit confirmation of this revision. Material changes require a new revision and confirmation record. The exact Status, Revision, and Confirmation evidence fields are checked by `pnpm project:init`.
